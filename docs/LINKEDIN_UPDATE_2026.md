## Experiência / Projetos em destaque

### Fazer o Bem — Projeto independente

Plataforma de ajuda mútua em sandbox/staging construída com Java 21, Spring Boot, PostgreSQL, Redis e Flyway. O projeto trabalha segregação de funções, dupla aprovação, ledger e auditoria encadeados, WebAuthn, idempotência de pagamentos, webhook assinado, replay protection, reconciliação, carga/concorrência, chaos/DR e Production Readiness.

Situação atual: NO-GO para dinheiro real até conclusão de pentest independente, validações jurídica/LGPD, rehearsal no staging real e homologação contratual do provedor financeiro.

### HATP Authority Firewall — Projeto independente

API B2B para autorização de ações críticas de agentes de IA. Implementa decisões ALLOW, DENY e HUMAN_REQUIRED, Passkeys/WebAuthn, transaction binding, proteção contra replay, escopos de API e isolamento por organização.

### MatchHub — Projeto independente

Backend Java/Spring Boot/PostgreSQL integrado a dashboard Next.js, com autenticação, regras transacionais, controle concorrente de vagas, Docker, testes e publicação cloud.

### PlayMatch — Projeto independente

Aplicativo Flutter/Firebase para organização de partidas, com autenticação, mapas, geolocalização, chat, notificações, avaliações e moderação.
